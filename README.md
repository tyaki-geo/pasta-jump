# pasta-jump
パスタで棒高跳びしたらイタリア人に発狂されますか？  
https://tyaki-geo.github.io/pasta-jump/

## 遊び方

1. 走っているとバーと突き箱が現れ、地面のゲージに帯が流れてくる。帯の中心（赤）が固定の白いバーに重なる瞬間にタップ（PCはクリック/スペース）してパスタを突き、そのまま押しっぱなしにする
2. パスタがしなって体が持ち上がる。もう一度帯の中心がバーに重なる瞬間に指を離して手を放す（離さないと自動で離れる）
3. 結果は確率で決まる（超ハードモード）
   - 超える確率: バー中心からのずれ(px)に応じて指数的に下がる（突く・離すの積）。帯は 黄→オレンジ→赤(中心) のグラデーションで表示。完璧なタイミングでも上限は約5.5%で、最良のパラメーター設定でも全体で約5%
   - バーが高いほど・パスタが短いほど成功しにくい
   - 折れる確率: 突いた時点で判定。水分量が多いほど・太いほど折れにくく、長いほど折れやすい。折れるときは長い2本と短いかけらの3つに折れる
   - しなり: 水分量が多いほど大きい。帯の広がり: 太いほど狭い
   - 水分量は 5〜15% の範囲（0%は粉、100%は水になってしまうため）
   - 帯の流れる速さ（×0.5〜×2）も調整可能。速いほどずれ(px)が時間あたり大きくなり難しい
   - パスタの水分量・太さ・長さ・バーの高さ・帯の速さはスタート画面で調整可能

スマホは横向き推奨。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + ビルド
npm test         # テスト
```
