# pasta-jump
パスタで棒高跳びしたらイタリア人に発狂されますか？  
https://tyaki-geo.github.io/pasta-jump/

## 遊び方

1. 走っているとバーと突き箱が現れ、地面のゲージに緑ゾーンが流れてくる。緑が固定の白いバーに重なったらタップ（PCはクリック/スペース）してパスタを突き、そのまま押しっぱなしにする（緑から外れても突くことはできるが、成功しにくくなる）
2. パスタがしなって体が持ち上がる。もう一度緑がバーに重なったら指を離して手を放す（離さないと自動で離れる）
3. 結果は確率で決まる
   - 超える確率: 突く・離すの両方で緑の帯を正確に捉えるほど高い。帯の外では指数的に下がる（帯は無色→黄→緑のグラデーションで表示）。バーが高いほど・パスタが短いほど下がる
   - 折れる確率: 突いた時点で判定。水分量が多いほど・太いほど折れにくく、長いほど折れやすい
   - しなり: 水分量が多いほど大きい
   - 緑の帯の幅: 太いほど狭い
   - パスタの水分量・太さ・長さ・バーの高さはスタート画面で調整可能

スマホは横向き推奨。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + ビルド
npm test         # テスト
```
