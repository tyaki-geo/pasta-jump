# pasta-jump
パスタで棒高跳びしたらイタリア人に発狂されますか？  
https://tyaki-geo.github.io/pasta-jump/

## 遊び方

1. 走っているとバーと突き箱が現れる。箱が近づくとパスタの先端が下がるので、タイミングよくタップ（PCはクリック/スペース）してパスタを突く
2. パスタがしなって体が持ち上がる。ゲージの緑のゾーンでもう一度タップして手を離す
3. 結果は確率で決まる（折れる確率・超えられる確率・バーの高さはスタート画面で調整可能。タイミングが良いほど成功しやすい）

スマホは横向き推奨。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + ビルド
npm test         # テスト
```
